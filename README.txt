Biciclette Produtos - site estático moderno

COMO PUBLICAR NO VERCEL
1) Entre em https://vercel.com/new
2) Escolha Import > Deploy manually ou arraste a pasta/ZIP
3) Suba o conteúdo deste pacote, mantendo index.html na raiz
4) Framework Preset: Other
5) Build Command: deixe vazio
6) Output Directory: deixe vazio ou coloque .
7) Clique em Deploy

COMO EDITAR OS LINKS
1) Abra assets/products.js
2) Troque amazon e mercadoLivre pelos seus links de afiliado
3) Para adicionar produto, copie um bloco {...} e edite nome, categoria, descrição, imagem e links

IMPORTANTE
O arquivo index.html precisa ficar na raiz do projeto.
A estrutura correta é:
/index.html
/assets/styles.css
/assets/app.js
/assets/products.js
